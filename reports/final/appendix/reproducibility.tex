\section{Reproducibility Commands and Environment}
\label{app:reproducibility}

The report package is built from the PaperMemory repository root. The recorded environment for the final package is branch \artifact{codex/papermemory-evidence-agent}, baseline commit \artifact{6884d738df9d685bad4f5a673a7d13a7bc2fb691}, Python 3.12.7, Node.js v22.18.0, and npm 10.9.3.

The final report package was compiled with:
\begin{verbatim}
cd reports/final
tectonic -X compile --outdir . --outfmt pdf --untrusted main.tex
\end{verbatim}

The report uses only a small set of local evidence artifacts. They are kept out of References because they are project evidence rather than external literature. Unless noted otherwise, filenames in Table~\ref{tab:local-evidence-registry} live under \artifact{reports/final/results/}.
